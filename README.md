# 100-Days-of-Python-Coding-Challenges

100 Days of Python Coding Challenges — solving Python interview problems daily with practical solutions, explanations, and time complexity analysis.

This repository contains daily Python practice exercises and interview-style problem solutions. Each script focuses on a specific problem-solving concept and is organized by day.

## Project Structure

```text
100-Days-of-Python-Coding-Challenges/
├── README.md
├── day 01/
│   ├── 01_even_odd.py
│   ├── 02_palindrome.py
│   ├── 03_factorial.py
│   └── 05_prime.py
├── day 02/
│   ├── 01_reverse_string.py
│   ├── 02_count_vowels_consonants.py
│   ├── 03_largest_number.py
│   ├── 04_remove_duplicates.py
│   └── 05_character_frequency.py
└── .gitignore (if present in the repo)
```

## Included Challenges

### Day 01
- `01_even_odd.py` — checks whether a number is even or odd
- `02_palindrome.py` — validates whether a string is a palindrome
- `03_factorial.py` — calculates the factorial of a number
- `05_prime.py` — checks whether a number is prime

### Day 02
- `01_reverse_string.py` — reverses a given string
- `02_count_vowels_consonants.py` — counts vowels and consonants in a string
- `03_largest_number.py` — finds the largest number from input values
- `04_remove_duplicates.py` — removes duplicate elements from a list
- `05_character_frequency.py` — counts character frequency in a string

## How to Run

Navigate to a day folder and run the Python script with:

```bash
python filename.py
```

Example:

```bash
python "day 01/01_even_odd.py"
```
