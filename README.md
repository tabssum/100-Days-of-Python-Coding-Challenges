# 100-Days-of-Python-Coding-Challenges

A practical Python practice repository focused on interview-style problem solving, daily logic building, and readable implementations. The repository currently contains challenges for Days 01–07; new days can be added as the series grows.

## Repository Overview

The exercises build skills in:

- input and output handling
- conditionals, loops, and iteration
- string manipulation
- list and dictionary operations
- number logic and digit processing
- basic algorithms and functional tools
- reasoning about implementation constraints and edge cases

## Daily Challenges

- [Day 01](./day%2001/README.md) — Python basics, conditionals, loops, and core number/string logic
- [Day 02](./day%2002/README.md) — string processing, list manipulation, and frequency counting
- [Day 03](./day%2003/README.md) — digit operations, number manipulation, and list frequencies
- [Day 04](./day%2004/README.md) — list and string challenges, including common elements, anagrams, and missing values
- [Day 05](./day%2005/README.md) — list differences, duplicate removal, grouping, perfect numbers, and dictionary merging
- [Day 06](./day%2006/README.md) — list intersection, longest-word selection, list rotation, and string compression
- [Day 07](./day%2007/README.md) — functional-style transformations and aggregation with `map()`, `filter()`, and `reduce()`

Each day's README describes its exercises, implementation details, and run commands. Some files currently contain only a problem statement and are not yet implemented; see the relevant daily README for their status.

## How to Run

Run a Python script from the repository root, quoting folder names because they contain spaces. For example:

```bash
python "day 01/01_even_odd.py"
python "day 03/01_sum_of_digits.py"
python "day 05/01_maximum-difference.py"
python "day 06/02_longest_word.py"
python "day 07/01_number_square_with_map_fun.py"
```

See each day's README for the full list of available run commands and notes about incomplete exercises.

## Learning Focus

These challenges encourage you to:

- write clear, readable Python code
- break problem statements into manageable steps
- build and compare different problem-solving approaches
- understand complexity, input assumptions, and edge cases
- practice practical coding-interview patterns
