# Day 02: String and List Manipulation Challenges

This folder contains Python challenges centered on string processing, counting, and list operations. These exercises build practical problem-solving habits for interviews and daily coding practice.

## Problems Included

### 1. Reverse a String
File: `01_reverse_string.py`

Reverses the characters in a string.

Example:
```python
Enter a string: python
Reverse of the string: nohtyp
```

Concepts:
- slicing
- string manipulation
- loops

### 2. Count Vowels and Consonants
File: `02_count_vowels_consonants.py`

Counts how many vowels and consonants are present in a user-provided string.

Example:
```python
Enter a string: hello
Vowels: 2
Consonants: 3
```

Concepts:
- character checking
- conditional logic
- string iteration

### 3. Largest Number
File: `03_largest_number.py`

Finds the largest number from multiple user inputs.

Example:
```python
Enter the first number: 12
Enter the second number: 45
Enter the third number: 28
Largest number is 45
```

Concepts:
- comparisons
- conditionals
- multiple variable handling

### 4. Remove Duplicates
File: `04_remove_duplicates.py`

Removes repeated items from a list while preserving order.

Example:
```python
Enter numbers separated by spaces: 1 2 2 3 4 4
List after removing duplicates: [1, 2, 3, 4]
```

Concepts:
- list operations
- set logic
- preserving order

### 5. Character Frequency
File: `05_character_frequency.py`

Counts how many times each character appears in a string.

Example:
```python
Enter a string: banana
{'b': 1, 'a': 3, 'n': 2}
```

Concepts:
- dictionaries
- frequency counting
- iteration over characters

## Run a Script

```bash
python "day 02/01_reverse_string.py"
```
